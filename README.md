# SkillPath – Student Career Readiness Platform

SkillPath is a web application that helps students manage their profiles, select target careers, track skills, and analyze skill gaps to improve career readiness.

## Live Demo

- **Frontend:** https://skillpath-frontend-coral.vercel.app/
- **Backend API:** https://skillpath-backend-96dk.onrender.com/
- **Students API:** https://skillpath-backend-96dk.onrender.com/api/students

## Technologies Used

- HTML
- CSS
- JavaScript
- Vercel for frontend deployment
- GitHub for version control

## Features

- Student profile management
- Target career selection
- Skill tracking
- Skill-gap analysis
- Dashboard overview
